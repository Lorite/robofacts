# Cite RoboFACTS

If you use RoboFACTS in your research, please cite the paper that describes it.

> Alejandro Lorite-Mora. RoboFACTS: A Declarative Experiment Design Framework for Multi-Robot Trials in Simulation and on Hardware. In Proceedings of the 42nd ACM/SIGAPP Symposium on Applied Computing (SAC '27), Gwangju, South Korea, April 5 to 9, 2027. DOI to come.

The file [`CITATION.cff`](https://github.com/Lorite/robofacts/blob/main/CITATION.cff) in the repository holds the same reference, and GitHub shows it as "Cite this repository". The pre-registered predictions of the paper's studies are in [`studies/sac2027/`](https://github.com/Lorite/robofacts/tree/main/studies/sac2027).
